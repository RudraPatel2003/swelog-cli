Reconstruct a day you missed using the `--date`, `--yesterday`, `--last-friday`, `--week-of`, and `--last-week` flags.

## Backfilling a day

```sh
# reset your work file to its default content
swelog reset

# write yesterday's notes into the work file
...

# fetch activity from external sources
swelog fetch github --yesterday
swelog fetch google-calendar --yesterday
swelog fetch linear --yesterday

# option 1: log the day
swelog log --yesterday

# option 2: summarize the day
swelog summarize --yesterday
```

For any other day, use `--last-friday` or `--date MM-DD-YYYY` as below.

### Backfill flags

| Command                        | Backfill flag       | Shortcuts                      |
| ------------------------------ | ------------------- | ------------------------------ |
| `swelog log`                   | `--date MM-DD-YYYY` | `--yesterday`, `--last-friday` |
| `swelog fetch github`          | `--date MM-DD-YYYY` | `--yesterday`, `--last-friday` |
| `swelog fetch google-calendar` | `--date MM-DD-YYYY` | `--yesterday`, `--last-friday` |
| `swelog fetch linear`          | `--date MM-DD-YYYY` | `--yesterday`, `--last-friday` |
| `swelog summarize day`         | `--date MM-DD-YYYY` | `--yesterday`, `--last-friday` |

## Backfilling a week

If it is Monday and you forgot to summarize last week's notes, use the `--last-week` flag as below

```sh
swelog summarize week --last-week
```

To target a different week, use `--week-of` as below.

```sh
swelog summarize week --week-of MM-DD-YYYY
```
