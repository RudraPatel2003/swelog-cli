title: Google Calendar
description: Record the meetings you had on a day into your work file.
---

Fetch your Google Calendar events for a given day.

## Usage

Fetch today's meetings:

```sh
swelog fetch google-calendar
```

## Backfilling

To backfill a previous date, provide `MM-DD-YYYY`:

```sh
swelog fetch google-calendar --date 08-17-2026
```

`--yesterday` does the same for the day before:

```sh
swelog fetch google-calendar --yesterday
```

For last Friday, use `--last-friday` instead of working out the date:

```sh
swelog fetch google-calendar --last-friday
```

## Output

The generated section contains your meetings for the day, ordered by start time.

```markdown
## Google Calendar

- 10:00 AM - 10:15 AM | Standup
- ~~11:00 AM - 11:30 AM | Eng all-hands~~
- 1:00 PM - 2:00 PM | Design review
- 3:00 PM - 4:00 PM | Focus block
```

Swelog records the following events:

| Event                              | Recorded       |
| ---------------------------------- | -------------- |
| A timed event you accepted         | Yes            |
| A timed event you never replied to | Yes            |
| A solo hold, such as a focus block | Yes            |
| An event you declined              | Struck through |
| An event the organizer cancelled   | Struck through |
| An all-day event                   | No             |

## Limitations

Swelog only reads the primary calendar of the account that authorized.

To record a different account's calendar, authorize as that account instead. See
[Switching accounts](#switching-accounts).

## Switching accounts

Clear the stored authorization and fetch again:

```sh
swelog auth clear google-calendar
swelog fetch google-calendar
```

The next fetch starts a new browser authorization flow, where you can pick a
different Google account.
