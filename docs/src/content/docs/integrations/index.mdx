## Quickly fetch all configured integrations

```sh
swelog fetch all
```

## See which integrations are configured

```sh
swelog fetch status
```

## How they fit into the work file

The default work file contains only `## Priorities` and `## Log`. Running any integration command creates a section for it.

```sh
swelog fetch github # creates "## GitHub"
swelog fetch google-calendar # creates "## Google Calendar"
swelog fetch linear # creates "## Linear"
```

:::caution[Integration sections are managed data]
Swelog finds each integration's section by its heading (such as `## GitHub`), so do not rename them.
:::
