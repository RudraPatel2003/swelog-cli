Record the pull requests you opened, merged, closed, and reviewed into your work file.

## Usage

```sh
swelog fetch github
```

The first run asks for a
[GitHub personal access token](https://github.com/settings/tokens) with the
`repo` scope and stores it in your operating system keyring.

## Backfilling

To fetch a previous date, provide `MM-DD-YYYY`:

```sh
swelog fetch github --date 08-17-2026
```

For the previous day, use `--yesterday` instead of working out the date:

```sh
swelog fetch github --yesterday
```

For last Friday, use `--last-friday` instead of working out the date:

```sh
swelog fetch github --last-friday
```

## What gets recorded

- **Opened**: pull requests you created on the date.
- **Merged**: pull requests you authored that were merged on the date.
- **Closed**: pull requests you authored that were closed without merging on the
  date.
- **Reviewed**: other people's pull requests where you submitted a review on the
  date. Pending reviews and reviews of your own pull requests are not included.

Reviews are matched by the UTC time they were submitted.
