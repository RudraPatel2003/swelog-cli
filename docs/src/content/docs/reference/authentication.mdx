---
title: Authentication
description: How swelog stores, inspects, and clears your credentials.
---

Swelog stores every credential in your operating system's credential store

- Keychain on macOS
- Credential Manager on Windows
- Secret Service on Linux

| Credential                    | Used by                                       | How it is obtained         |
| ----------------------------- | --------------------------------------------- | -------------------------- |
| GitHub token                  | `swelog fetch github`                         | Prompted on first use      |
| OpenAI API key                | `swelog summarize` with `"llm": "openAi"`     | Prompted on first use      |
| OpenRouter API key            | `swelog summarize` with `"llm": "openRouter"` | Prompted on first use      |
| Anthropic API key             | `swelog summarize` with `"llm": "anthropic"`  | Prompted on first use      |
| Linear authorization          | `swelog fetch linear`                         | Browser OAuth on first use |
| Google Calendar authorization | `swelog fetch google-calendar`                | Browser OAuth on first use |
| Sentry auth token             | `swelog fetch sentry`                         | Prompted on first use      |

## Inspecting stored credentials

Review what is stored. This does not print the values, only how the credential is resolved.

```sh
swelog auth status
```

## Clearing a credential

If a credential is revoked or rejected, clear it and run the command again to
enter a new one. Every authorization error names this command:

```sh
swelog auth clear github
swelog auth clear --all
```

`swelog auth clear` accepts `github`, `open-ai`, `open-router`, `anthropic`,
`linear`, `google-calendar`, and `sentry`.

## Environment variable overrides

`GITHUB_TOKEN`, `OPENAI_API_KEY`, `OPENROUTER_API_KEY`, `ANTHROPIC_API_KEY`, and
`SENTRY_AUTH_TOKEN` take precedence over the keyring when set. When one of these is set, `swelog auth status` reports it instead of the stored
value.

Linear and Google Calendar are authorized through the browser and have no
environment variable override.
